Approved on 2026-11-10 (rows 1–84). Any later change to a row needs a new approval.

- **Old** is today's text. A dash (—) means the string is new.
- Greek uses the polite plural (σας), like the rest of the creation flow today.
- Strings marked **reused** already exist in the app with exactly these words and are not changing. They are listed so you can see the whole flow.
